# SVINLINE

Пародийный букмекер на виртуальные SV₽. React + TypeScript + Vite, без сервера: состояние хранится в localStorage.

## Команды
- `npm install` — установка
- `npm run dev` — запуск для разработки
- `npm test` — тесты логики ставок
- `npm run build` — сборка в `dist/`

## Структура
- `src/data.ts` — события, акции, новости, тексты «О компании», стартовый баланс. Меняй контент здесь.
- `src/logic.ts` — расчёт ставок, выплат, возвратов (чистые функции, покрыты тестами в `logic.test.ts`).
- `src/App.tsx` — интерфейс. `src/index.css` — стили и цвета (переменные в `:root`).

## Как добавить событие
В `src/data.ts` добавь объект в `EVENTS`: `{id:'e7',cat:0,title:'…',desc:'…',out:[['Да',2.0],['Нет',1.5]]}`. `id` должен быть уникальным, `cat` — номер категории из `CATS`.

## Публикация на GitHub Pages
1. Залей проект в репозиторий, ветка `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. После пуша `.github/workflows/deploy.yml` сам соберёт и опубликует сайт. Путь `base` подставляется автоматически по имени репозитория.
