# Картинки карточек «Игры 24/7»

Положи сюда свою картинку для любой игры — она автоматически заменит
рисованную миниатюру на карточке. Имя файла = id игры:

- `crash.png` — Хряк-Крэш
- `bonanza.png` — Бонанза
- `roulette.png` — Корыто Фортуны
- `plinko.png` — Пяточок-Плинко
- `puddles.png` — Грязевые лужи
- `ruble.png` — Курс рубля
- `blackjack.png` — Хрякджек
- `pick.png` — Кирка
- `mine.png` — Шахта

Формат: png, jpg, webp, avif или gif. Рекомендуемый размер ~300×190
(карточка обрежет по принципу «cover»). Если файла нет — показывается
CSS-миниатюра. Имя можно писать и с суффиксом: `crash.v2.png` тоже сработает.
